# Global Football Player Performance Dashboard

## 📊 Overview

An interactive Power BI dashboard designed to analyze global football
player performance across countries, teams, competitions, and players.

The dashboard provides insights into goals, assists, matches played,
minutes played, progressive carries, progressive passes, progressive
runs, penalty performance, and disciplinary records.

## 🔍 Key Analysis

### ⚽ Goals & Assists

The dashboard compares player attacking performance using:

- Goals scored
- Assists
- Goals + Assists per 90 minutes

This allows comparison of attacking contributions across top
performing players.

### 🟨 Red & Yellow Cards

Disciplinary performance is analyzed across teams using:

- Red cards
- Yellow cards

This helps identify differences in disciplinary records between teams.

### 🎯 Penalty Performance

Penalty performance is analyzed using:

- Average penalties scored
- Average penalty attempts

This provides insight into penalty performance at the player level.

### 🌍 Matches Played by Country

The dashboard compares the number of matches played across different
countries, providing a geographic view of football activity.

### 🏃 Progressive Carries, Passes & Runs

Team-level performance is analyzed using:

- Progressive carries
- Progressive passes
- Progressive runs

These metrics help evaluate ball progression and attacking movement
across teams.

### ⏱️ Minutes Played & Full 90s Equivalent

The dashboard analyzes total minutes played across countries and
provides a full 90s equivalent comparison.

This helps understand player participation and playing-time
distribution.

### 🌎 Countries & Teams

A geographic visualization displays teams and their associated
countries, providing a global perspective of the football dataset.

## 🎛️ Interactive Filters

The dashboard includes filters for:
