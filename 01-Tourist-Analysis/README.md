# Tourist Analysis Dashboard

## 📊 Overview

An interactive Power BI dashboard designed to analyze tourist behavior,
travel patterns, spending, destinations, accommodation preferences,
and feedback.

The dashboard consists of three interactive pages:

- **Home** – Dashboard landing page and navigation
- **Main** – Overview of tourist trends, spending, travel costs, and requirements
- **Analysis** – Detailed analysis of tourist demographics, destinations,
  accommodation, transport, and travel agencies

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Visualization
- Data Analysis

## 🔍 Key Analysis

### Tourist Demographics
- Analyzed tourist distribution across gender and age groups.
- Identified the most represented age group among tourists.

### Travel Trends
- Analyzed monthly tourist volumes.
- Compared tourist activity across major destination cities.
- Examined different travel purposes.

### Spending & Revenue
- Compared spending across major destination cities.
- Analyzed revenue generated by different travel agencies.
- Evaluated trip costs across different transportation modes.

### Accommodation & Experience
- Compared average feedback scores across accommodation types.
- Analyzed special requirements of tourists.
- Examined feedback patterns to understand the tourist experience.
