# GDP Dashboard (2020–2025)

## 📊 Overview

An interactive Power BI dashboard designed to analyze global GDP
performance from 2020 to 2025 across 196 countries.

The dashboard provides insights into GDP, GDP per capita, global GDP
share, GDP growth, and country-level economic performance through
interactive visualizations and filtering.

## 🔍 Key Analysis

### 🌎 Country-Level GDP Analysis

The dashboard provides a country-level comparison of GDP performance
between 2020 and 2025.

Users can filter the dashboard by country to explore and compare
economic performance across different nations.

### 💰 Average GDP by Country

Average GDP from 2020 to 2025 is compared across countries to identify
the largest economies within the dataset.

### 📈 GDP Growth Analysis

The dashboard analyzes GDP growth between 2020 and 2025 across
countries, helping identify countries with significant changes in
economic performance.

### 🌐 Global GDP Share

Global GDP share is analyzed across countries to understand the
relative contribution of different economies to the global economy.

### 🗺️ GDP per Capita

A world map is used to visualize GDP per capita across countries,
providing a geographic perspective of economic performance.

### 📊 Total GDP by Country

Total GDP across the 2020–2025 period is compared between countries,
highlighting the economies with the highest overall GDP.
