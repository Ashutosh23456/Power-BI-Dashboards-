# Blinkit Sales Analysis Dashboard

## 📊 Overview

An interactive Power BI dashboard designed to analyze Blinkit's sales
performance across different outlet types, outlet sizes, locations,
product categories, fat-content segments, and outlet establishment
years.

The dashboard provides insights into total sales, average sales,
number of items, customer ratings, outlet performance, product
categories, and location-based sales performance.

## 🔍 Key Analysis

### 🏪 Outlet Performance

The dashboard analyzes sales performance across different outlet
types, including:

- Supermarket Type 1
- Grocery Store
- Supermarket Type 2
- Supermarket Type 3

This helps compare the contribution of different outlet formats
to overall sales.

### 📍 Outlet Location Analysis

Outlet performance is analyzed across different location tiers:

- Tier 1
- Tier 2
- Tier 3

This provides insight into how outlet location influences sales
performance.

### 📏 Outlet Size Analysis

The dashboard compares outlets across different size categories:

- Small
- Medium
- High

This helps identify the relationship between outlet size and
sales performance.

### 🥫 Product & Item Type Analysis

Sales are analyzed across different product categories, including:

- Fruits and Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Health and Hygiene
- Meat
- Soft Drinks
- Breads
- Hard Drinks
- Others
- Starchy Foods
- Breakfast
- Seafood

This helps identify the product categories contributing most to
overall sales.

### 🥗 Fat Content Analysis

Products are segmented based on fat content:

- Low Fat
- Regular

The dashboard compares sales across fat-content categories and
different outlet tiers.

### 📅 Outlet Establishment Trend

Sales are analyzed based on outlet establishment year to identify
changes in sales performance over time.

This helps understand how outlet maturity relates to sales.

### ⭐ Customer Ratings

The dashboard tracks the average customer rating across the dataset,
providing an indicator of overall customer satisfaction.
