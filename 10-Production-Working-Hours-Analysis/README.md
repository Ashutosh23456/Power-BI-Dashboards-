# Production Working Hours Analysis Dashboard

## 📊 Overview

An interactive Power BI dashboard designed to analyze employee
working hours, overtime, shortfall hours, planned hours, earnings,
and workforce distribution.

The dashboard provides insights into employee productivity, overtime
patterns, earnings across employees and cities, division-wise work
distribution, gender diversity, and average hourly rates.

## 🔍 Key Analysis

### ⏱️ Working Hours Analysis

The dashboard compares planned working hours with actual worked hours
to understand overall workforce utilization and productivity.

Key metrics include:

- Total Worked Hours
- Total Planned Hours
- Total Shortfall Hours
- Total Overtime Hours

### 🕐 Overtime Analysis

Employee-level overtime hours are analyzed to identify employees
with higher overtime workloads.

This helps highlight overtime patterns and differences in employee
workload.

### 💰 Employee Earnings

The dashboard analyzes earnings across individual employees to identify
differences in compensation and employee-level earnings.

### 🌆 City-Wise Overtime Earnings

Overtime earnings are compared across cities including:

- Toronto
- Tokyo
- Sydney
- Mumbai
- Mexican
- Chicago
- Cape Town
- Berlin
- Barcelona

This provides insight into geographic differences in overtime costs.

### 👥 Gender Diversity

The dashboard provides a gender distribution analysis of the workforce,
allowing comparison between male and female employees.

### 🏢 Division-Wise Work Distribution

Working hours are analyzed across different divisions:

- Supporting
- Photography
- Management

The dashboard compares planned hours with actual worked hours for
each division.

### 💵 Average Hourly Rate

Average hourly rates are analyzed across different employee roles,
including:

- Coordinator
- Cameraman
- Assistant

This helps compare compensation rates across job roles.

### 🏙️ City & Division Filtering

Interactive filters allow users to analyze the dashboard based on:

- City
- Division

This enables focused analysis of workforce performance across
different locations and organizational divisions.
