# Weather & Air Quality Dashboard

## 📊 Overview

An interactive Power BI dashboard designed to provide a comprehensive
view of weather conditions and air quality for Hyderabad.

The dashboard combines current weather information, multi-day weather
forecasts, air quality indicators, atmospheric conditions, sunrise and
sunset timings, and precipitation forecasts into a single interactive
visualization.

## 🔍 Key Analysis

### 🌡️ Weather Conditions

The dashboard provides an overview of the current weather conditions
for Hyderabad, including:

- Current temperature
- Weather condition
- Humidity
- Wind speed
- Visibility
- Atmospheric pressure
- UV index
- Precipitation

### 📅 Weather Forecast

A multi-day weather forecast provides temperature trends across the
forecast period.

The dashboard displays forecast information for:

- Wednesday
- Thursday
- Friday
- Saturday
- Sunday
- Monday
- Tuesday

This allows users to quickly understand upcoming temperature changes.

### 🌧️ Chance of Rain

The dashboard compares the probability of rain across different
forecast days.

This helps identify days with a higher likelihood of precipitation.

### 🌅 Sunrise & Sunset

The dashboard displays daily:

- Sunrise time
- Sunset time

This provides useful information about daylight duration and timing.

### 🌿 Air Quality Index

The dashboard provides an air quality overview using pollutant
measurements including:

- PM10
- PM2.5
- SO2
- NO2
- O3
- CO

The overall PM10 reading is also visualized using an AQI-style gauge.

### 🏭 Pollutant Analysis

Individual pollutant levels are displayed to provide a more detailed
view of air quality conditions.

This allows users to identify the concentration of different
air pollutants rather than relying only on a single air quality score.
